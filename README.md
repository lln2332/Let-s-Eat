# 饭点了 · 午餐大转盘

面向个人用户的午餐选择小工具。打开转盘，把“今天吃什么”交给一点运气。

## 使用

下载仓库后，直接用浏览器打开 `index.html`，无需安装依赖。

如需通过本机服务访问，在仓库目录运行：

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。

## 功能

- 打开即可抽取午餐，预算通过快捷标签选择。
- 口味与商圈使用可选偏好面板，全页无下拉框。
- 近三天不重复、跳过店铺、搜索餐厅与地图查找。
- 添加私藏只需填写店名，分类、商圈和预算可选。
- 支持桌面与手机屏幕。

## 保存与数据

偏好、私藏和用餐记录仅保存在当前浏览器的本地存储中。页面使用 HTML、CSS 与原生 JavaScript，不需要后端服务。

内置 46 家午餐候选，预算为参考估算；出发前请在地图确认门店位置、营业情况和菜单。
